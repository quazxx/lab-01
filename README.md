**Тема:** калькулятор арифметических выражений и конвертер единиц измерения. Интерфейс - командная строка, пакет `toolkit`.

## Возможности программы

Команды:

```text
python -m toolkit calc "EXPRESSION"
python -m toolkit convert VALUE --from UNIT --to UNIT
python -m toolkit --help
```

Калькулятор понимает целые и дробные числа, операции `+ - * /`, унарный плюс и минус перед числом и пробелы. Умножение и деление важнее сложения и вычитания. `eval` не используется.

Конвертер переводит единицы внутри одной группы:

- длина: `mm`, `cm`, `m`, `km`
- масса: `g`, `kg`
- температура: `c`, `f`, `k`

Регистр единиц не важен. Между группами перевод запрещён. Температура ниже абсолютного нуля дает ошибку. Успех заканчивается кодом 0, ошибка пишется в stderr и заканчивается кодом 2.

## Процесс считывания выражения

Три отдельных шага:

1. `tokenize` режет строку на числа и операторы.
2. `validate` смотрит, что выражение не пустое, нет мусорного символа, нет двух бинарных операторов подряд и не потерян операнд.
3. `calculate` сначала приклеивает унарный знак к числу, потом считает `*` и `/`, потом `+` и `-`.

Разбор `2*-3`:

```text
tokenize:  number 2, operator *, operator -, number 3
validate:  после * число ещё не пришло, минус - унарный, затем число 3. Так можно.
calculate: числа [2, -3], оператор *.  2 * -3 = -6
```

То же самое с пробелами: `2 * -3`.

`1+-2` считается как `1 + (-2) = -1`. Плюс здесь бинарный, минус - знак числа.

`2*/3` - ошибка «Два оператора подряд»: слэш не может быть знаком числа. Пустая строка - «Пустое выражение». `2+a` - «Недопустимый символ». `1/0` - «Деление на ноль».

## Устройство конвертера

Длина переводится через метры, масса через граммы. Температура - через Цельсий:

```text
°F = °C * 9/5 + 32
K  = °C + 273.15
```
```bash
python -m toolkit convert 1.5 --from kg --to g
python -m toolkit convert 0 --from c --to f
``` 

Первая команда печатает 1500: полтора килограмма — это 1500 граммов. Вторая печатает 32: 0 °C — это 32 °F.
